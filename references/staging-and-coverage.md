# 空间、调度与可剪覆盖

## 先确定观众必须理解什么

继承当前剧本的事件、人物选择和对白，只决定它们怎样被看见、听见。从原文提取需要承载的变化：行动起因/结果、信息、对白语义、听者反应、关系变化、空间方向、物件状态、连接和必要补镜。按实际内容选择，不重做一遍叙事开发。

可用简表 `义务 ID / 来源版本与原文 / 必须看见或听见的证据 / 容易误读成什么 / 最晚出现时点 / 承载镜头`。一镜可有多项义务，一项可由多镜承载；不能只数镜头而漏掉结果。分镜转换任务不得通过新造事件来补齐表格。

## 空间必须能行动

定入口/出口、相邻区域、人与物动线、看见/听见条件、隐私与遮挡、核心家具、手部和身体动作空间。前场秩序与后场劳动可以提供戏剧材料。没有测量时用相对位置，注明是设计候选。

复杂接触、多路行进、遮挡揭示或固定空间复用时，用平面/白模验证；简单对白不强制建 3D。白模若未实际制作就不能报告完成。二维路径相交不证明三维接触，静帧不能证明整个路径畅通。

调度回答人物为何移动或留下；摄影回答观众为何移动注意力。不要为“电影感”让摄影机不停漂移。固定镜头、居中、直视、近景、大量人物均可有明确目的。

## 分镜最小生产信息

```text
shot ID / 来源场次与版本 / 任务与覆盖义务
故事时间与状态前驱 / 剪辑时间区间
entry：人物位置、姿态、视线、手部、物件和已经发生的事
景别/角度/注意焦点；摄影变化的触发与落点
镜内行动/对白 Cue/听者反应/必要声音
exit：物件、位置、知识和身体状态变化
参考职责 / 必要首帧或关键相位 / 未确定项
```

这是需要时的信息，不强制九栏 Word；简单场景可直接在镜头描述里表达。单镜头可承载多个阶段；先按注意力、行动和剪辑确定镜头，再分配时间，不能先均分场数、镜头数或秒数再往里填戏。批量制图前的试制选择依 [主流程](../SKILL.md)，无需另设分镜审批轮次。

## 状态与剪辑

分别检查事件发生、人物知情、观众看见的时点。首帧只取 entry，触发、峰值或结束另按需要选相位；各图的用途和时点先写清。闪回沿明确故事前驱继承，不能把未来伤势带回过去。跨镜保持眼线、轴线、动作方向、道具位置、手部占用、湿损状态和未完成动作。

轴线可有意改变，但给观众重新定向的依据；视线匹配和空间建立为理解服务，不是机械“绝不越轴”。建立镜不必每场都有，若省略需仍能理解动作对象与位置关系。

## 身体动作专项

仅当本次内容确有追逐、阻拦、打斗、摔投等行动时使用。否定词“不要打斗”不触发扩写。

每个必要节点：距离/支撑/手部 → 主动行为 → 对方或环境反馈 → 接触或错失 → 位置/资源/伤损变化 → 后续可行动状态。躲开不补命中，单方压制不强制对方反击。法术与变形依已建能力规则，不凭空增加。

关键接触、遮挡、方向和优势变化要可读；比较错峰、机位、拆镜或声音辅助，保护因果。没有动作捕捉、骨骼或碰撞仿真，不声称力学验证。首帧不能提前画出命中后火花和伤势。

## 三层覆盖证据

1. 文本义务分配：每个必须信息有计划承载。
2. 调度/白模：实际核对的站位、视线、遮挡和可用机位。
3. 连续预演/成片：观众在真实时长内能理解动作和变化。

三层不能互相冒充。若素材不足，标记缺哪一类证据；不要为了减少生成量删掉关键反应、对白或结果。
