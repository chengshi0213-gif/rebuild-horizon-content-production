# 摄影技术规格

按交付需要从叙事意图到模型无关规格，再映射执行参数。数字需单位、来源和状态：实测、校准虚拟、名义值、意图或未知。给图片 Prompt 写“35mm”不证明像素遵循真实镜头。

| 类别 | 明确什么 |
| --- | --- |
| 画面 | 容器宽高、活动区域、像素宽高比、裁切/补边/缩放策略；横竖派生保护哪些叙事信息 |
| 安全区 | 动作、字幕、平台遮挡区域依当前目的平台；未知时做假设，不硬编码通用百分比 |
| 机位 | 相对高度/方向/距离、轴线侧、前中后景；校准空间才使用精确坐标 |
| 镜头 | 视角和投影、空间感觉、主体环境比例；等效焦距用于比较视角，不代表同样透视与景深 |
| 焦点 | 谁需要清楚、谁可模糊；焦点变化的触发、目标与时间；不能只写浅景深 |
| 运动 | 起止构图、方向、路径、速度变化、跟随/等待对象与落点；复合运动要兼容 |
| 模糊 | 哪些信息必须清晰，允许何种运动模糊；快门角要有帧率才有时间意义 |
| 光线 | 光源位置、软硬、颜色关系、主体/环境亮度与保护区域；像素亮度比不等于现场照度比 |
| 光学性格 | 畸变、炫光、颗粒等是否服务画面；不能每镜机械加瑕疵 |
| 匹配 | 相邻镜曝光/肤色/方向/景深意图的相容或有意差异 |

透视主要取决于机位与主体几何关系，不能用换焦段冒充机位移动。未校准优先“齐眼高度、稍偏侧、人物与门同处可读景深”等可观察关系。

色彩管理分清源编码假设、工作空间、创意 look、显示/输出变换。模型 PNG 不能冒称相机 RAW、Log 或场景线性。若采用 LUT/OCIO/ACES，沿项目已存在的配置与版本；不默认强加依赖。比较样片时用一致显示条件或注明差异。

适配映射标为可直接控制、近似、未测试或不支持。原生参数可复现只证明请求相同，不证明真实光学被模拟。支持情况依当前工具和实际试验；不能从第三方旧模型画像推定本机能力。

图像能检查构图/颜色/单时点焦点意图，动态才支持速度/路径与焦点转移，最终输出元数据才支持交付规格。技术检查与审美选择分开。
