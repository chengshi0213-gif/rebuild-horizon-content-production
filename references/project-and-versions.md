# 项目、决定归属与交接

持续项目或跨环节变更时读取。这里维护协作规则；各专业页只处理本领域问题。

## 当前稿只认一个来源

沿用项目已有的源文件和命名。持续项目的 `project.md` 是导航，不再复制一遍剧本和所有表格：

```text
本次目标与交付范围
固定约定：用户设定、题材体验、规格、允许改动
当前采用来源：剧本 / 角色画风 / 镜头 / 声音时间（只列已有项的路径与版本）
当前问题、已有证据、尚未验证的关键部分
这次改变了什么 → 受影响的已有产物 → 下一项工作
```

上述信息可用几行写完。单次小任务留在答复即可。来源许可放素材记录，不抄到每份工作表。用户的采用指令与助手在授权内选用的工作候选分别说明，不能伪造批准。

同一内容只在源稿编辑；分镜表、提示词、字幕、网页等派生物引用它。项目有生成器就更新源数据再重建相关输出，避免手改派生稿后被下一次构建覆盖。没有程序时手工同步也可，不为此另建平台或数据库。

## 哪一层作决定

“层”是同一助手的工作职责，不要求多人、多个 Agent 或分阶段签字。

| 工作 | 消费什么 / 决定什么 | 交给下游什么 / 怎样判断 |
| --- | --- | --- |
| 世界取材 | 用户本体、实际资料与明确假设；推演尝试及后果 | 有来源的事件/反应及可选分支。能改变选择才值得继续采集；材料不自动成为剧情事实 |
| 剧本 | 选中的材料与作品目标；决定事件、能力、信息揭示、人物选择、对白、结局 | 当前场景稿、必要规则与未决问题。选择有依据、交换有回应、作品承诺有落点 |
| 角色与画风 | 角色设定与用途；决定稳定外貌、风格及可变范围 | 已选规格/真实参考及验证范围。能辨认、能比较；单张成功不等于全角度稳定 |
| 分镜与表演 | 当前剧本、身份与空间；决定机位、走位、表演、切点 | 当前镜头稿及必要入口/出口状态、Cue 引用。信息可见可听，动作与注意力可承载 |
| 声音与时间 | 当前对白和动作；决定读法、take、同步与时间分配 | 同一时间轴及估算/实测依据。超时若需删改意义，回剧本决定 |
| 编译与执行 | 当前镜头、参考与时间；表达工具输入、生成和检查结果 | 实际输入、输出、选择与问题。工具困难不能自行改剧情、身份或关键动作 |

每层在授权的设计空间内完成本职决定。固定事实发生冲突时回到对应源稿；摄影角度、无叙事影响的动作细化等常规选择直接处理，不为所有细节报批。

## 交接只传采用结果与问题

下游读取：**采用来源 + 本次要表达的变化 + 尚未确定的部分**。无需重新产出上游整套分析。当前来源够用时直接继续；缺口会实质改变本次结果才回查。

结果区分：候选、当前采用、待复核；检查结论另记“检查了什么”。采用可基于用户选择或已有授权内的工作决定，不等于验证通过。缺实图/录音/动态时仍可交相应文本方案，不能升级证据。

正式采用或已交付的成果保留可恢复版本。采用内容改变时更新修订标识，下游同步注明所消费的修订；可沿用文件名，但同一版本号不能指代前后不同内容。备份能支持恢复，不能单独解决当前引用的版本歧义。

普通草稿沿项目习惯编辑，不为每句话另存一套文件。稳定 ID 不依赖镜头排序；重排后仍能追溯同一场、镜头或 Cue。旧项目无需批量重命名。

## 变更只沿实际依赖传播

先改最早出错的来源，再标记消费该版本的已有产物。尚未制作的东西只是后续输入，不创建空文件或虚构失效任务。

| 改变 | 核对实际受影响的部分 |
| --- | --- |
| 事件、能力、人物知情、结果 | 相关场次/对白及后续状态；依赖它们的分镜、资产、声音、Prompt |
| 台词、读法、录音 | 对应 Cue、时长、反应触发、字幕、口型、剪辑及视频输入 |
| 稳定外貌、服装、道具、画风 | 对应参考与使用该参考的图像/视频 |
| 走位、手部、机位、切点 | 有关镜头状态、图像、预演及跨镜承接 |
| 文件路径、内容、权利 | 消费方可访问性、清单与已记录的哈希 |

影响可跨多个后继镜头，直到该状态被后续事件覆盖；按故事前驱追踪，不按“第几个镜头以后”硬编码。回看前后连接点即可，不因局部改动重生成无关资产。

返修只记：具体观察 → 原因所属层 → 最小改动 → 受影响产物 → 怎样复核。纯生成偏差留在执行层；原设计不可行则先改设计。若每轮都得添加新限制才能保住同一选择，比较更简单的行动或叙事安排，再决定保留还是换案。停止反复尝试的条件是问题解决、需要新的上游选择，或已达到当前授权的试制范围。

## 兼容旧项目

旧 CinePipe S0–S10 可作为历史阶段标签继续引用，不把它们恢复为必经轮次。独立对话不依赖平台、Notion 或多个 Agent。

接入真实运行器时先读其 schema，并做字段映射；本包不宣称兼容旧 JSON API。不要把自然语言稿直接送进未核验的旧消费者。
