# 图片与视频编译

当前镜头和参考需要转成工具输入时读取。编译以 [采用来源](project-and-versions.md) 为依据，不重新决定剧情、稳定身份或对白。

## 取当前画面的事实

确认产物用途：角色校准、资产、风格样片、首帧、相位关键帧、技术示意或视频。参考只承担已选定的身份、服装、空间、光色等职责；冲突回对应来源解决。

从当前镜头读取人物、状态、空间、注意力、声音和允许变化。只注入这一图在场人物及可见物件的状态，伤侧、持物和约束明确属于谁；全场状态表留作核对，不整表塞入每张图。

单图只表达一个时点。首帧取入口；峰值图取对应相位。未来动作可帮助理解上下文，不能提前出现在入口图中。结果用途在生成前确定，失败的首帧不能改名为关键帧就算通过。

## 编译与执行记录

选择已可用的工具，核对当前支持的参数与参考机制；尚未选工具时交模型无关规格，不猜平台语法。各模型从同一规格独立编译，不从另一模型 Prompt 二次翻译。

用具体可见/可听关系表达内容。文本长度按承载能力选择；形貌术语经过压缩，不粘贴研究词典。负面项用于具体失败，不代替正向状态与实图检查。

生产记录关联目标 ID、来源版本、**实际发送**的 Prompt、工具参数、输入参考与实际输出。可复用模板单独标为模板，不能当作历史调用证据；不虚构 seed、模型版本、图片 ID 或接口。

## 检查图片

生成或编辑按当前请求和宿主工具要求执行。先看待编辑原图，再明确本轮失败变量与应保留区域。

实图核对身份、单时点状态、空间、构图可读性、画风及相邻镜承接。参考职责标签不保证模型能隔离人物脸形；发现同脸或状态串人时回查输入。静图不能证明动作顺畅或口型。

## 检查视频

使用当前参考、动作顺序、触发、时长、spoken text 和时间依据，保留跨镜 Cue。生成段可留余量，长度服从表演与工具，不能把戏机械均分。

查看片段中的身份、接触与支撑、物件、眼线、速度、镜头路径、发声与余态。首尾帧不证明中间路径合理。失败按 [返修规则](project-and-versions.md) 判断是设计冲突、参考问题、时间不合、工具限制还是生成偏差，然后只更新受影响输入与结果。
