# 转折与目标模型

共同规则见[索引](index.md)，2026-09-06 核对。以下用途是 本地原有方法的适配判断。

## Dan Wells 七点结构

[本人参与讲解](https://writingexcuses.com/writing-excuses-7-41-seven-point-story-structure/)。起始状态、转折一、施压一、中点、施压二、转折二、结局。Wells 说明其从角色扮演资料吸收此法，不将其宣称为本人原创。

从结局倒推起始状态，再建立可信的转折与压力；中点常用于从反应走向主动，后段使解决方案具备条件。压力不是固定死导师或加敌人，可是选择空间缩小。例：想被接纳→受邀→规则排斥→主动改变办法→失去支持→发现合作方式→完成行动。允许悲剧结果，七点不是七场或七镜。

## Michael Hauge 六阶段五转折

[作者官方说明](https://storymastery.com/screenplay-structure-five-key-turning-points-successful-scripts/)。六阶段为建置、新处境、推进、复杂化与更高风险、最后冲刺、余波；五个连接点为机会、计划改变、无法回头、重大挫败、高潮。

使用时对照外部可见目标与人物因恐惧受限的内部选择；先写每次转折实际改变什么。原模型位置比例仅作参考。例：接下运送任务，发现货物是生命，继续服从变成保护；不可仅用内心旁白标出成长。可以用于较长篇幅，短篇不强迫全套心理转化。

## John Yorke 五幕

[官方说明](https://www.johnyorkestory.com/five-act-structure/)。通过比三幕更细的推进层级观察激励、中部转向、危机和收束。不是把任意故事平均切五块，也不把所有传统五幕模型视为同一版本。

使用：标记每阶段如何改变主角理解和选择，尤其检查中部认识之后的行动后果。例：相信规则→按规则争取→发现规则代价→承担反抗后果→形成新关系。适合中段与长线诊断；允许不对称篇幅，不把来源关于“所有故事”的宣传性主张作为硬规则。

## David Siegel 九幕

[作者原始页面](https://nineactstructure.com/)。Act 0 冲突前史；1 建立环境；2 坏事/谜事发生；3 引入主角；4 投入；5 追逐原目标；6 揭示导致目标反转；7 追逐新目标；8 收束。Act 0 可以不上银幕。核心是信息改变目标，非三幕各分三段。

使用：先检验反转信息是否有前因，是否真的改变目标，再安排此前线索。例：追捕被误认为窃贼的人，发现失物被用于救灾，转而保护救援。只换战术不自动构成新目标。适合目标重估故事，不强求单目标故事造阴谋；不采纳作者未经独立证实的影片占比或固定年代长度。
