# 整体与序列模型

共同使用规则见[索引](index.md)。核对日期 2026-09-06。只读选中节，不把三种模型同时强加给故事。

## Syd Field 三幕式

来源：[作者官方工作表](https://sydfield.com/syd_resources/the-paradigm-worksheet/)。功能摘要：建立处境与戏剧问题；进入更持续的对抗；通过最终行动解决或改变问题。主要情节点把行动转入新方向。

使用：先写主角面对什么问题、两个主要方向变化和结局；检查变化的原因与选择，再填场景。适合整体大纲诊断，不把激励事件和第一幕终点自动视为同一事件。没有新方向时先修因果，不加一个无关事故凑节点。允许非线性叙述，但事件因果与观众获知顺序分别记录。

自拟例：想独自守桥的角色接受任务；错误判断使同伴受困；最终放弃独占功劳共同救援。具体篇幅由故事决定，不强制 25/50/25。

## 序列法／八序列法

来源：[Gulino 出版社说明](https://www.bloomsbury.com/uk/screenwriting-9781628922394/)。长片可组织为多个有局部戏剧任务的序列，原书介绍约十五页一个序列。八是常用组织规模，不是每部作品的必选数。

使用：为当前长故事划分局部目标、障碍、局部结果及引出的下一问题；中段重复时比较相邻序列是否真的改变任务。序列可包含多场，每场仍须可演。系列可借用局部回报思想，但不能声称一集天然等于一个电影序列。

自拟例：找到渡口→争取船→发现船载不了同伴→寻找另一条路线。若四段只是重复问路，就没有有效阶段推进。可合并或增加序列，以实际因果为准，不把短篇塞满八段。

## Save the Cat! 十五节拍

来源：[官方节拍库](https://savethecat.com/beat-sheets)、[官方十五拍表](https://savethecat.com/wp-content/uploads/2013/12/STC_BeatSheetRev3.pdf)。简要功能序列：开场形象、主题提示、铺陈、催化事件、犹疑、进入第二幕、B线、类型承诺展开、中点、压力逼近、一切尽失、低谷反思、进入第三幕、终局、结束形象。

使用：先确定类型体验与人物变化，选择能体现各功能的具体行动；再检查中点之后是否改变风险、低谷是否来自此前行为、终局是否兑现。B线不等于必须恋爱，主题提示不等于说教台词，类型展开不等于所有类型都要搞笑。

自拟例：开场不肯借伞、结尾主动撑伞，可形成行为对照；中间必须有使变化成立的选择，不能只靠首尾图像宣称成长。可合并或省略功能并说明，不强制长片页码或每集完整十五拍。
