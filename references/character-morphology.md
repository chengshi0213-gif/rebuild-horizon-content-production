# 人物长相：五层描述与专业词汇

目标是可辨认、可复核、能跨镜保持的形象，而不是把每个人优化成同一张“标准美脸”。先区分原创设计、参考复现、局部编辑和画风转换。

医学与医美资料在这里提供结构分层、表面形态和观察方法；不提供临床诊断或治疗。照片里的表面表现不等于真实骨骼测量。

## 五层

| 层 | 记录内容 | 常见混淆 |
| --- | --- | --- |
| 1 结构与轮廓 | 颅面总体长宽、额部倾斜、颧区、下颌轮廓、颏部前后关系 | 把侧光阴影当骨骼凹陷；“下巴尖”同时混用宽度和前突 |
| 2 局部形状与比例 | 眼裂、眼睑、眉、鼻、唇、耳的可见形状、间距和相互关系 | 用“精致五官”替代具体区别；所有尺寸自动理想化 |
| 3 软组织、年龄与皮肤 | 颊部体积、眼周、口周、下颌缘软组织、纹理与局部色差 | 一切年龄变化只靠皱纹；把毛孔和痣当人格标志 |
| 4 可变外观与状态 | 头发、妆容、表情、发声、光线、机位、近摄透视 | 妆容修改顺带改眼鼻骨形；笑脸当永久身份 |
| 5 图谱、锁定与验证 | 正/侧/三分之二等实际参考，稳定特征、允许变化和检查条件 | 多张图互相不是同一人；只看正面就批准侧面 |

先选少量最有辨识度的稳定特征，再按当前视角补充局部细节。不要求把所有术语塞进 Prompt。目标可以不对称、衰老、普通、夸张；设计约束由用户决定。

## 部位词汇：从专业知识转换成可见目标

| 部位 | 可以描述的维度 | 观察与限制 |
| --- | --- | --- |
| 额/颞 | 额部高度、宽度、曲率、侧面后倾；颞区表面凹凸 | 发际线改变可见额高，不等于额骨变化 |
| 眉/眶周 | 眉位置与走向、眉眼距离；上眶缘的表面起伏 | 眉妆、额肌活动和头部仰俯影响外观 |
| 眼睑/眼裂 | 眼裂横向长度、高度、内外眦相对走向、上睑褶皱可见性、下睑轮廓 | 眼裂大小不等于眼球大小；表情改变开合 |
| 颧/颊 | 颧区横向宽感、前向凸度、颊部体积、凹面过渡 | “颧骨高”要澄清是位置、外扩还是前突；单张图难分骨与脂肪 |
| 鼻 | 鼻根高度、鼻背曲线、鼻尖投影/旋转、鼻翼宽度、鼻小柱可见量 | 正面鼻宽不代表侧面投影；鼻基底与鼻翼不是同一部位 |
| 唇/口周 | 上下唇红比例、唇峰、唇珠、口裂宽度、口角静态位置、人中外观 | 张口、笑、抿唇不是结构锁；“嘟唇”可指形状也可指动作 |
| 颏/下颌 | 颏部宽度、高度、前突与唇的关系；下颌角轮廓、下颌缘连续性 | 颏部前突与下颌整体前移不能混为一谈；姿态与颈部软组织影响边界 |
| 耳/颈 | 耳廓轮廓、贴附/外展、耳垂、颈部外观比例 | 头发遮挡时不虚构隐藏细节 |
| 皮肤 | 局部纹理密度、光泽、色差、雀斑/痣位置、瘢痕表面特征 | 不由外观诊断病因；不要自动磨皮和对称化 |

医美中“三庭五眼”、比例线、鼻唇角、面部轮廓关系可作为设计和比较语言，不能当普遍审美法则或所有族群适用的正常标准。没有标准化摄影/尺度/标志点不输出伪精确毫米数。图像生成模型收到角度数值也不等于会精确执行。

年龄涉及骨、软组织、皮肤等多层变化，个体差异明显。外观设计可描述眼周体积、组织松弛感、纹理、发色等组合，不能按年龄自动套同一条医学因果链。民族、性别不作为自动生成具体几何的充分条件。

## 一张角色卡如何写

```text
身份 ID / 版本 / 来源与许可
稳定辨识点：整体轮廓 + 2–5 个当前最重要的差异（按需增减）
视角证据：正面 / 侧面 / 三分之二，各图证明哪一项
软组织与皮肤：设计目标、自然不对称、必须保留的标记
可变量：妆发、服装、表情、年龄版本、风格变体
不能据现图判断的部位
验收：换视角/光线/表情后哪些关系应保持
```

例如原创设定可写“下脸略长，颏尖偏宽而非锐尖；鼻背微凸，鼻尖投影中等；外眼角略高于内眼角；左眉尾比右侧更平”。这是设计候选，不是从人物种族或性格推导，更不是保证模型一次执行成功。
