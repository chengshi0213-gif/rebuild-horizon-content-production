# 传统形貌词的视觉转译

用于用户已经使用“面相、骨相、天庭、地阁、丹凤眼”等描述，或有历史造型需求。将文化称谓拆成可画的目标；不同流派/语境的词义可能不同，下面是造型候选，不是古籍权威校勘。

| 词 | 可用的观察/设计方向 | 要澄清之处 |
| --- | --- | --- |
| 天庭饱满 | 额部表面曲率较连续、额区体积感 | 是额高、宽度还是前突；不推出聪明、福运 |
| 地阁方圆 | 颏与下脸的宽度、轮廓转折与圆钝程度 | 传统部位词不能代替具体视角；不推出财富与忠厚 |
| 印堂 | 眉间区域 | 宽窄、纹理、妆色另写；不以颜色诊断健康或运势 |
| 剑眉 | 眉形较直、眉尾方向明确，边缘/粗细按参考定 | 毛发形状与眉骨结构分开；不推出刚正或凶狠 |
| 丹凤眼 | 用户可能意指较修长眼裂及特定外眦走向 | 先看其参考，不固定成单眼皮或极端上挑；不推出算计 |
| 杏眼/桃花眼 | 对眼裂曲线、开合、眼尾或眼周状态的审美称呼 | 无唯一几何模板；表情和妆容不可误锁为骨形 |
| 鹰钩鼻 | 鼻背曲线和鼻尖向下的可见倾向 | 分开鼻背凸度与鼻尖旋转；不附人格含义 |
| 骨相清晰 | 额、眶、颧、下颌等轮廓转折相对可见 | 可能来自光、体脂或妆容，不直接等于骨骼测量 |

角色若被设定为“面相师”，其话语可以作为虚构人物信念呈现；叙事事实仍不能由长相自动推出品格和命运。设计反派可依据故事选择造型，但不能把“某种眼鼻的人就是坏人”写成系统规则。

有词义歧义时，先提出可视化解释并标为待选，不停在玄学形容词。既有参考能说明目标时直接沿用。已核对的辞典与未核实的古籍范围见 [来源页](sources.md)。
