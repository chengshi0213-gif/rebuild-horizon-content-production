# 世界推演取材：先发生，再选择怎样讲

用于原创、改编、日常戏、角色反应和“没有生活、只有编剧说理”的诊断。它在写作之前产生材料，也在发现具体违和时局部回放；不只做完稿逻辑检查。教学片的演示事实依实测取材，无角色冲突时不硬造世界模拟。

## 1. 补足会改变行动的材料

从已有素材提取人物日常任务、地点、工作流程、时间约束、物件、关系和信息来源。先查“决定这次反应的空白”，不要漫无目标下载素材。

例如写修鞋摊，值得查等待取件、材料未干、照明、收款和熟客如何打断工作；不能只收集“市井烟火气”照片。职业/制度/历史细节优先读相关机构、从业者原始记录、公开操作资料和原始影像。每条保留来源、时间地点、适用边界及矛盾证据。评论、采访、观察属个例，不自动代表群体；没有检索到就写“创作假设”。

材料可很普通：排队占位、手套湿了不好拿手机、剩饭、快递电话、没问完的问题、惯常帮忙。是否保留取决于它如何改变行动、关系或观看经验，而非戏剧评分。

## 2. 建立够用的世界状态

按需要展开，不要求小戏填写全表：

- 硬现实或题材本体：空间、身体、物质、该世界允许的超自然能力。
- 制度与程序：谁有权限、申请/决定/通知/执行各要多久；规则可能有执行差异。
- 资源：时间、钱、库存、工具、精力、位置、手部占用。
- 社会关系：客观身份/义务，与主观信任/羞耻/怨恨分开。
- 个体：当下目标、惯用策略、欲望冲突、疲惫、记忆、承诺、误判。
- 信息：真相是什么；谁通过什么渠道知道；谁相信/不信；观众何时看到。
- 持续过程与未来义务：旅行、排队、修理、流言、病程、借款、交期、待回复。

这些层不是“制度永远压倒资源”的万能公式。真实人可能违反制度；要裁决是否可做、会被谁发现及后果。神话世界依其已建本体，不用现实主义抹去母本规则。

## 3. 运行一段生活

推进单位可以是一件事、一次交谈或一天，服从取材缺口。每轮：

1. **环境更新**：外部事件、持续过程、到期义务变化。
2. **各人感知**：只给其能看见/听见/记得的信息；世界真相不能直接注入角色。
3. **提出行动**：此人想改变什么，具体怎么做，忽略了什么；他可以拒绝、敷衍、不回应或保持日常任务。
4. **裁决后果**：核对时间、身体、工具、阻碍、他人独立选择和程序。角色只控制尝试，不能决定别人感动或事情成功。
5. **写入状态**：成功、部分成功、失败、等待分别有什么时间/物质/信息/关系代价；旧承诺继续存在。
6. **记录可观察材料**：行为、话语、物件变化、公开反应，以及有来源的私人解释。解释不一定要变成台词。

这是内部推演方法，不是六轮交付。记录对当前写作有用的变化即可；多人视角可在同一助手内模拟，不宣称独立 Agent 实验，也不因引用研究而部署模拟器或 MCP。

## 4. 让材料在交付中可见

对故事开发，交一组与篇幅相称的材料卡或简短事件日志。局部修订可只交一条。最低信息：

```text
材料 ID / 事实来源或创作假设
处境与原有任务 → 看见/误解了什么 → 尝试 → 结果
可拍的动作、物件、话语或空白
改变了什么；未改变什么；后续仍欠什么
候选用途；进入剧本后补采用处或舍弃原因
```

不强制每场若干伏笔、每十二条取三条、不按高冲突阈值删掉生活片段。若新一轮已不产生与任务相关的差异，停止推演，转入选择和写作。保留少量未采用材料供后续使用即可。

## 5. 从事件到故事

先辨认不可逆选择、关系偏移、资源临界、认知差、义务到期及有趣的日常，再把材料交给 [叙事](narrative.md) 选择。倒叙是讲述顺序变化，不改世界发生顺序。

推演先允许人物按已有工具、信息和目标采取普通行动，不预设他们必须走向某个高潮。出现轻易可行的办法时，保留它对原方案的挑战；不要临时让每样工具失灵、每个帮手离场。人物也可以因恐惧、习惯或自尊放弃可行办法，但依据应来自这个人及当时处境。保留真正改变选案的一条分支，比补写大量支持既定结局的材料更有用。

比较分支时可只变一个条件，如“他看到了手机消息/没看到”。报告结果对哪些假设敏感。模拟产生频率不是现实概率；虚构出的对话不是访谈记录；合理性推演不能替代民俗、医学、法律等事实核验。

## 6. 反应为何不像人

检查是否：全员服务主角；没人有自己的事；自动知道秘密；像咨询师复述感受；一句话就深刻理解并转变；每句都工整互文；结尾代作者总结；环境与劳动不会打断；失败无代价；情绪每镜归零。

修订用“任务—信息—选择—代价”解释具体反应。允许有文化、会讲道理、强烈表态或突然失控的人；自然不等于词穷、全员支支吾吾、禁止比喻。突变应有这次事件和既往压力的依据，而非一律渐变。

## 原创示例：钥匙没有递出去

**假设**：夜班店员正封冻品箱；同事已三次迟还仓库钥匙。现在同事说“就拿一下，马上还”。店员知道库存表还没签，不知道同事其实要拿充电器。

**一次推演**：店员抬肘示意腰间钥匙，手没停；同事伸手摸到钥匙圈，发现被鞋带系着。店员说“这回别整串拿走”。同事没有解释充电器，只解下一把。店员腾出的手压回翘起的封箱胶带。

**材料用途**：鞋带、整串钥匙和未停的劳动呈现已有信任问题；没有逼人物说“我对你失去了信任”。同事究竟拿什么仍是后续信息，不让店员提前反应。不是实地观察，不拿它证明真实店铺惯例。

本方法综合本地事实域与公开世界模拟研究；来源及未运行项见 [来源页](sources.md)。
